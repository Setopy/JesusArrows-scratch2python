Quick start for grown-ups

  1. Open or print the book. Read For grown-ups near the back first.
  2. Open the notebook in Colab with the button above, then choose File → Save a copy in Drive so the work is saved.
  3. Run the magic first cell, !pip install ColabTurtlePlus, each time you open the notebook.
  4. Do one mission per session, about 20 to 30 minutes, with your child at the keyboard.
Install ColabTurtlePlus (with Plus). The similarly named ColabTurtle is a different library and won't work with this book. Everything was tested in Colab in November 2026.

Source files, research notes and build scripts are on GitHub.
